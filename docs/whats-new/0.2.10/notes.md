A tidier message list: files, labels and spaces line up as one shelf.
- Labels and spaces are now soft cards the same height as the file card, so a row reads as one neat line.
- The "+2" for more files sits inside the file card, so it's clear it counts files.
- Spaces show their full path, like "Acme / Website", with their colour or logo.
- A star is a small badge on the sender's picture, so a starred email no longer takes an extra line.
