# Code signing policy

Free code signing provided by [SignPath.io](https://signpath.io), certificate by [SignPath Foundation](https://signpath.org).

Kite's Windows releases (the installer and `kite.exe`) are built from this repository by GitHub Actions and signed only after a maintainer approves each release. Builds made anywhere else are not signed. (Kite has applied to SignPath Foundation; releases before approval are unsigned.)

## Team roles

Kite is maintained by one person, who holds every role:

- **Authors** (commit without further review): [Mark Steyn](https://github.com/TheeHappyCoder)
- **Reviewers** (review changes from anyone else): [Mark Steyn](https://github.com/TheeHappyCoder)
- **Approvers** (approve each signing request): [Mark Steyn](https://github.com/TheeHappyCoder)

Every team member uses multi-factor authentication on GitHub and SignPath.

## Privacy

Kite sends nothing to the author. What it sends to other services, and how to turn each one off, is in the [privacy policy](PRIVACY.md).
